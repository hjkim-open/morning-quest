# 엄마 목소리 넣는 법

- 칭찬: 이 폴더에 `praise1.mp3` ~ `praise9.mp3` (m4a도 가능)
- 경고: `sounds/warn/` 폴더에 `warn1.mp3` ~ `warn9.mp3` (m4a도 가능)
- 여러 개면 매번 랜덤 재생, 없으면 기본 효과음으로 대체


1. 엄마 목소리를 녹음해서 mp3로 저장하세요.
2. 파일 이름을 `praise1.mp3`, `praise2.mp3`, ... `praise9.mp3` 순서로 이 폴더에 넣으세요.
3. 앱이 자동으로 찾아서, 퀘스트 완료할 때마다 랜덤으로 재생해요.
4. 파일이 하나도 없으면 기본 팡파레 소리가 나요.

추천 멘트 예시:
- "우리 딸 최고다~ 잘했어!"
- "역시 우리 딸이야, 오늘도 해냈네!"
- "장하다 장해~ 시험도 붙겠다!"
